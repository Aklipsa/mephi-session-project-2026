## Примечания

- Графическая оболочка в системе не устанавливалась — все операции выполнялись в текстовом режиме. В качестве скриншотов используются снимки терминала с выводом команд; итоговый скриншот страницы — вывод `curl http://localhost/`.
- Все команды выполнялись от root, если не указано иное; проверка пользовательского доступа — через `sudo -u <user>`.
- Монтирование настроено по метке тома `LABEL=MEPHI_WEB` — не по имени устройства, чтобы не зависеть от порядка нумерации дисков.
- Для ограничения входа кураторов используется PAM-модуль pam_access (`access.conf`) — запрет действует только на локальный вход.
- Проверка наследования ACL выполнена на реальных файлах (`test1.txt`), после проверки тестовые данные удалены.
